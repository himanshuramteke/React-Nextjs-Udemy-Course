## Steps for TS project setup.

1. ` npm init -y` It will install basic `package.json` file.
2. `npm i -D typescript` It will add typescript dev-dependency into your project.
3. `npx tsc init` This command will create a new tsconfig.json. After this you can start writing typescript.
4. `npx tsc` this command will create a dist folder which means all your ts code will be converted into js and you can check your converted code in dist/index.js folder.
5. Run your ts file by this command `node dist/index.js`
